1.1 Introduction Hospital management system

Hospital Management System (HMS) is an integrated information system designed to manage all aspects of hospital operations efficiently. These operations include patient registration, appointment scheduling, medical records management, billing, staff management, and reporting. In modern healthcare institutions, the use of database systems is essential to ensure accuracy, efficiency and reliability of information. Hospitals generate a large amount of data every day, includindetails, doctor schedules, treatment records, laboratory results, and financial transactions. Managing this data manually is inefficient and prone to errors. Therefore, a computerized Hospital Management System database is required to store, retrieve, update, and manage hospital data effectively.
